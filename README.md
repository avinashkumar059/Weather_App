# 🌦️ Weather App
A modern and responsive Weather Application built with React.js, Vite, Tailwind CSS and OpenWeatherMap API. The app provides real-time weather information for any city worldwide

# 🛠️ Tech Stack
●React.js

● Vite

●JavaScript (ES6+)

●CSS / Tailwind CSS

●OpenWeatherMap API

●Axios / Fetch API

# 📌 API Used
OpenWeatherMap Current Weather API
